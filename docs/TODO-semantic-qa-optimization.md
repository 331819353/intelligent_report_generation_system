## 4. 已完成：正式智能问答六阶段链路

- [x] 资产管理中心不承载测试性质的“语义演练”页面或导航。
- [x] 正式 `query-turns` 接口在服务端执行完整链路，避免由页面拼接可信步骤。
- [x] **阶段 1**：用户问题整句向量化，检索指标库 Top 5。
- [x] **阶段 2**：Jieba/HMM 分词和词性标注；每个有效分词分别检索指标语义与
  维度语义，各取 Top 5。
- [x] **阶段 3**：LLM 综合原问题、整句 Top 5 和逐词 Top 5，输出意图、指标名称、
  维度含义、维度值和补充后的问题。
- [x] **阶段 4**：用维度含义与规范值检索决策图，展示指标、表名和 WHERE 候选。
- [x] **阶段 5**：LLM 在受控候选范围内过滤，保留最终 WHERE，并按意图组合。
- [x] **阶段 6**：只对全部 READY 的计划查询真实数据；任一指标未就绪时不执行
  不完整结果。
- [x] 智能问答页面展示候选、选择原因、阻断原因、最终计划和查询结果；完整分词
  轨迹同时随本轮响应返回，供后续压缩展示与审计。

## 5. 已完成：通用语义与时间处理

- [x] 使用 Jieba/HMM 做通用分词，不按测试问题预切词。
- [x] 分词只负责发现候选片段；实体含义由向量库、已发布语义资产和 LLM 共同确定，
  不要求 Jieba 独立解决业务实体识别。
- [x] 移除地域层级和中英文地域值的代码硬编码，别名与维度归属由语义资产配置。
- [x] 第 4 步“召回到候选”和第 5 步“证明后选择”分离；有候选但尚不能证明时，
  页面保留候选并明确阻断位置，不再把召回失败和过滤失败混为一个错误。
- [x] LLM 时间转换会读取真实字段 `valueType`、浏览器时区和服务端参考时间。
- [x] 区分时点、期间和截止语义；输出 `normalizedValue` 以及
  `[start, endExclusive)`。
- [x] 服务端重新校验 DATE/DATETIME 精度和区间，前端输入不能伪造时间边界。
- [x] “月底”等描述词可在 LLM 阶段转换为具体日期，并在最终计划中显示冻结后的
  时间范围。

## 6. 当前未完成：P0

- [x] `QA-P0-001` **正式智能问答接入同一六阶段链路。**
  `query-turns` 已在服务端执行 tokenize/整句召回/逐词召回/LLM 提取，并只把通过

- [x] `QA-P0-001A` **补齐歧义候选的人工确认闭环。**
  当指标或维度无法唯一证明时，响应需返回可确认的受治理候选；页面允许用户选择后
  以候选 ID/版本和并发基线重新提交，服务端再次校验，不能接受表名、WHERE 或 SQL。
  已实现指标编码与决策图 ID 的确认重提；服务端重新加载当前发布资产，未确认结果
  不执行。

- [ ] `QA-P0-002` **完成真实业务语义配置和兼容关系覆盖。**
  为目标业务域发布维度名称、维度类型、成员值、别名、指标—维度兼容关系和决策图。
  这项不能改成代码词表。
  验收：未知表达可通过配置新增后命中；未配置或不兼容的维度继续安全阻断。

- [ ] `QA-P0-003` **应用迁移并确认四类索引真实 READY。**
  在每个目标环境应用到最新迁移，等待指标、维度、成员和决策图向量回填完成。
  验收：命中测试区四类前提均为 READY，无长期 PENDING/FAILED。

- [ ] `QA-P0-004` **建立六阶段端到端黄金问题集。**
  至少覆盖：未见过的业务表达、纯指标、单维度、多维度、同义词、歧义词、无命中、
  不兼容维度、最近 N 天、本月、月底截止、同比/环比和多指标。
  验收：每题固定预期阶段、候选范围、最终计划或阻断码，不只校验最终文案。

- [ ] `QA-P0-005` **补齐目标业务域的成员与决策图重建闭环。**
  配置或画像变化后必须自动触发成员向量和决策图重建，并对旧 generation 失效。
  验收：新增语义配置后无需改代码即可命中，重复同步不会清空有效成员索引。
