## 0. 使用规则

1. 任务按 [04 §3](./04_实施规划与验收终稿.md) 的里程碑 M1～M6 组织；领任务先确认里程碑与依赖。
2. 状态按 BE / FE / E2E / BIZ 四层记账；勾选 `[x]` 表示该任务定义的全部交付完成，后端完成不得代表业务闭环。
3. 所有新页面、流程或显著视觉状态必须先出设计稿并取得用户确认（设计稿门禁）。
4. 新任务必须登记在本文件并声明六大支柱归属（见 [02 §3](./02_技术设计终稿.md)）；不得在本文件之外派发任务。
5. 数据库迁移编号已使用至 `000299`，新迁移顺延，不得复用；详见 [06_HANDOFF §4](./06_HANDOFF.md)。
